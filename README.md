# Kayla & Melquin — Sweet Seventeen Invitation

One responsive website with a gender-based invitation entry flow.

## Invitation flow
1. Guest chooses GIRLS or BOYS.
2. Guest types any name they want to use. Names are not validated against a guest list; the selected gender determines which checklist appears.
3. Girls see the girls' preparation checklist. Echa, Dhea, Michelle, and Misel do not see the overnight-only items.
4. Boys see the boys' preparation checklist.
5. Both views show the same combined gallery of 10 Kayla photos and 10 Melquin photos, mixed together without separate name headings.

**Privacy note:** This is a display-based separation, not password-protected access control. A visitor can return to the first screen and select either invitation. Do not use it to hide confidential information.

## Music
Add your own permitted copy of the audio file named `house-of-balloons.mp3` into the `music` folder. Music can only start after the visitor clicks the music control, because browsers block autoplay. It pauses when the tab is hidden or the page is left where supported.

## Publish with GitHub and Vercel
1. Extract this ZIP file.
2. Create a new GitHub repository.
3. Upload all files and folders inside `kayla-melquin-website` (not the ZIP itself).
4. Open Vercel and import the GitHub repository.
5. Keep the framework preset as **Other** and click **Deploy**.

No build command or output directory is needed; this is a static HTML website.
